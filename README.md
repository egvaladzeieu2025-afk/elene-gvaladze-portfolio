# Portfolio Publishing Bundle

This folder contains the exact static bundle intended for GitHub Pages.

- `index.html` is the standalone portfolio with embedded CSS and images.
- `.nojekyll` disables Jekyll processing.

Publish the contents of this folder at the root of the deployment repository. Do not publish the process documentation, course notes, source CV, or unconfirmed personal information alongside it.

The portfolio currently publishes at the repository's GitHub Pages URL. The intended custom domain, `elenegvaladze.me`, remains attached to an existing WordPress site and must not be redirected without a separate migration decision.
